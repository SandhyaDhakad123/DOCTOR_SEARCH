# Location Data

`india-cities.js` is derived from the MIT-licensed `cities.json` dataset in `nshntarora/Indian-Cities-JSON`.

Source: https://github.com/nshntarora/Indian-Cities-JSON
Raw source: https://raw.githubusercontent.com/nshntarora/Indian-Cities-JSON/master/cities.json

The file is geographic search data only and is separate from DoctorFinder doctor records.
